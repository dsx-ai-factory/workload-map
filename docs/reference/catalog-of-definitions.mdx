The catalog contains the pre-built, tested definitions that ship with Workload Map. The Go library and `kli` include the catalog, so they can read these workload types even when the cluster has no definition for them. This page explains how the catalog works and lists its definitions.

## How the Catalog Works

- The definitions are Go code in `pkg/catalog`. The repository generates them into YAML files in the `docs/catalog/` directory.
- The name of a definition follows the group, version, and kind of the workload, such as `leaderworkerset-x-k8s-io-leaderworkerset-v1`. The file has the same name with the `.yaml` extension.
- A definition in the cluster overrides the catalog definition for the same group, version, and kind. `kli` lists such a definition once, with the origin `cluster`.
- A definition marked `spec.experimental: true` is excluded by default. For more information, refer to [Use the CLI](../observability/use-the-cli.mdx#include-experimental-definitions).

To list the definitions in the catalog, run the following command:

```bash
kli definitions
```

To print one definition, give its name. The YAML output applies and validates as it is:

```bash
kli definitions kubeflow-org-pytorchjob-v1 -o yaml
```

To write your own definition, start from the catalog definition that is closest to your workload type. For more information, refer to [Define a Workload Type](../building-on-workload-map/define-a-workload-type.mdx).

## Experimental Definitions

The following definition is experimental. It is excluded from `kli` and the Headlamp plugin until you enable experimental definitions in each tool.

| Workload type | API version | Project | Definition | Components |
| --- | --- | --- | --- | --- |
| Workload | `kueue.x-k8s.io/v1beta2` | Kueue | [`kueue-x-k8s-io-workload-v1beta2`](https://github.com/dsx-ai-factory/workload-map/blob/main/docs/catalog/kueue-x-k8s-io-workload-v1beta2.yaml) | `workload` |

To include it in `kli`, use the `--catalog-experimental-definitions` option. For the Headlamp plugin, refer to [Include Experimental Definitions](../observability/use-the-headlamp-plugin.mdx#include-experimental-definitions).
